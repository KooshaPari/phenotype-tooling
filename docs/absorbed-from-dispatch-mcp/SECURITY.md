# Security Policy

## Reporting a Vulnerability

We take security seriously. **Please do not file public issues for security vulnerabilities.**

To report a vulnerability, use GitHub's private vulnerability reporting:

  https://github.com/KooshaPari/dispatch-mcp/security/advisories/new

Alternatively, email **security@phenotype.dev**.

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Affected versions

We will acknowledge receipt within 72 hours and provide a remediation timeline.

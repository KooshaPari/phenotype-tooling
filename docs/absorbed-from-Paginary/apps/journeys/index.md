# User Journeys

Comprehensive user journey documentation and workflow maps for Phenotype applications.

## Journey Types

- **Feature Journeys** — Step-by-step user flows for features
- **Onboarding Journeys** — New user and team onboarding flows
- **Integration Journeys** — Cross-system workflows and integrations
- **Operational Journeys** — Admin and operational task flows

## Documentation Structure

Journeys are documented with:
- **Personas** — User types and roles
- **Goals** — What users want to accomplish
- **Steps** — Detailed action sequences
- **Acceptance Criteria** — Definition of journey completion
- **Variations** — Alternative paths and edge cases

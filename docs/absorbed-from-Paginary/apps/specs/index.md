# PhenoSpecs

Comprehensive feature specifications and design documents for Phenotype projects.

## Document Types

- **Feature Specifications** — PRD, functional requirements, acceptance criteria
- **Architecture Decision Records** — Technical decisions and rationale
- **Design Documents** — System design and architecture diagrams
- **Planning** — Project plans and work breakdowns

## Structure

Specifications are organized by project and feature area. Use the sidebar to navigate.

::: tip
All specifications follow the Phenotype specification documentation system. See the governance guide for details.
:::

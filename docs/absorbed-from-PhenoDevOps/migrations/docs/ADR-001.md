# ADR-001: Go-Based Migration System

## Status
Accepted

## Context
Need a database migration system for the Phenotype ecosystem.

## Decision
Build a custom Go-based migration system with:
- Transactional safety
- Programmatic and SQL migrations
- Seeding capabilities
- Rollback support

## Rationale
Deep integration with Phenotype logging, configuration, and multi-tenancy requirements.

## Consequences
Complete control but maintenance burden.

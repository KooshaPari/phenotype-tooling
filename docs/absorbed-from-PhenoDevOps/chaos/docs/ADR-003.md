# ADR-003: Continuous Chaos in CI/CD

## Status
Accepted

## Context
Chaos engineering should be part of the regular delivery pipeline, not just ad-hoc testing.

## Decision
Integrate chaos experiments into CI/CD:
1. Pre-deployment chaos gates
2. Post-deployment smoke tests with chaos
3. Scheduled continuous chaos in staging
4. Chaos as quality gate for production

## Implementation

```yaml
chaos-gate:
  stage: quality-gate
  script:
    - litmus run --experiment network-latency
    - ./scripts/smoke-tests.sh
  allow_failure: false
```

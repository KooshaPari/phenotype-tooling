# ADR-002: Chaos Experiment Safety Controls

## Status
Accepted

## Context
Chaos experiments can cause real production issues if not properly controlled. Safety mechanisms are essential.

## Decision
Implement multi-layer safety:
1. **Automatic Abort**: Metric-based abort conditions
2. **Blast Radius**: Percentage-based targeting
3. **Timeboxing**: Maximum experiment duration
4. **Health Checks**: Pre-flight system validation
5. **Manual Override**: Immediate abort capability

## Implementation

```yaml
spec:
  experiments:
    - name: pod-cpu-hog
      spec:
        components:
          env:
            - name: TOTAL_CHAOS_DURATION
              value: '60'
            - name: CHAOS_INTERVAL
              value: '10'
            - name: TARGET_CONTAINER
              value: 'api'
  abortConditions:
    - metric: error_rate
      threshold: 5.0
      operator: greater_than
```

# ADR-001: Go-Based CI Pipeline Framework

## Status
Accepted

## Context
The Phenotype ecosystem requires CI/CD capabilities that:
1. Work consistently across local dev and CI environments
2. Support the Go-based toolchain
3. Enable reproducible builds
4. Provide clear pipeline observability
5. Support multiple CI platforms (GitHub Actions, GitLab CI)

## Decision
Build a Go-based pipeline framework that:
- Defines pipelines as code in Go
- Executes commands with proper context handling
- Supports stage-based execution
- Integrates with popular CI platforms
- Provides local execution for testing

## Rationale

### Why Custom Framework

1. **Unified Local/CI Experience**: Same pipeline code runs locally and in CI
2. **Type Safety**: Pipeline definitions are type-checked Go code
3. **Testing**: Pipeline logic can be unit tested
4. **Observability**: Structured logging integration
5. **Flexibility**: Programmatic pipeline generation

### Core Concepts

**Pipeline**: Collection of stages with dependencies
**Stage**: Named unit of work with commands
**Command**: Shell execution with timeout and environment

```go
pipeline := ci.New("phenotype-build").
    AddStage(ci.BuildStage("go build ./...")).
    AddStage(ci.TestStage("go test ./...")).
    AddStage(ci.LintStage("golangci-lint run"))
```

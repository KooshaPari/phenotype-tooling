# ADR-003: Pipeline Observability

## Status
Accepted

## Context
Pipeline execution requires comprehensive observability:
- Stage execution timing
- Success/failure rates
- Resource utilization
- Error correlation
- Historical trends

## Decision
Implement structured logging and metrics:
1. Structured slog for all pipeline events
2. Stage duration tracking
3. Error categorization
4. Context propagation for tracing
5. CI platform-native metrics integration

## Implementation

```go
func (p *Pipeline) Run(ctx context.Context) error {
    logger := slog.With("pipeline", p.name)
    logger.Info("pipeline starting")
    
    for _, stage := range p.stages {
        start := time.Now()
        err := p.runStage(ctx, stage)
        duration := time.Since(start)
        
        logger.Info("stage complete",
            "stage", stage.Name,
            "duration_ms", duration.Milliseconds(),
            "success", err == nil,
        )
        
        if err != nil {
            return err
        }
    }
    
    return nil
}
```

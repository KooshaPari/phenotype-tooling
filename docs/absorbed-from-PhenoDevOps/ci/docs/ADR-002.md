# ADR-002: Cross-Platform CI Support

## Status
Accepted

## Context
CI pipelines must run on:
- Linux (primary CI environment)
- macOS (local development, iOS builds)
- Windows (Windows-specific builds)

## Decision
Implement cross-platform support through:
1. Platform detection in pipeline runner
2. Platform-specific stage variants
3. Docker-based fallback for consistency
4. Clear platform requirements documentation

## Implementation

```go
type Stage struct {
    Name            string
    Commands        []string
    PlatformCommands map[string][]string // platform -> commands
    Env             map[string]string
}

func (s *Stage) CommandsForPlatform(platform string) []string {
    if cmds, ok := s.PlatformCommands[platform]; ok {
        return cmds
    }
    return s.Commands
}
```

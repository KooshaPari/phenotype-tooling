# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities by opening an issue on this repository with the label `security`.

We aim to acknowledge receipt within 48 hours and provide an initial assessment within 5 business days.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Disclosure Policy

- Vulnerabilities are disclosed publicly via GitHub Security Advisories after a fix is released.

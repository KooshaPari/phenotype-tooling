## 6. Contradictions and drift found

The task description's claim of contradictions inside `ARCHIVED.md:9` is
**not actionable** because `ARCHIVED.md` does not exist in this repo (verified
via `ls phenoXdd/ARCHIVED.md` and `git -C phenoXdd ls-files ARCHIVED.md`,
both returning nothing). The audit did, however, surface **other**
contradictions and drift items. Each is recorded below with a path:line
citation; **none were fixed in this PR** (T0 audit is read-only against
non-Markdown governance files).

### 6.1 `CLAUDE.md:15` — misleading development command

`CLAUDE.md:15` reads:

```
pip install -e ".[dev]" && pytest
```

This is a development command for a Python package. **No Python package exists
in this hub** — there is no `pyproject.toml`, `setup.py`, or `requirements.txt`
in the repo, and `docs/reference/adr.md:7` explicitly declares the hub
documentation-only with no runtime artefacts. The command is misleading to
agents and humans. **Recommendation**: replace lines `14-16` of `CLAUDE.md`
with either an empty `## Development Commands` section or a pointer to the
`docs/` VitePress build (`docs/package.json`) and the documentation-site
Playwright suite. Deferred from this PR — out of T0 scope; record and move on.

### 6.2 `AGENTS.md` — non-UTF-8 encoding + CR-LF line endings

`AGENTS.md` is a 497-byte text file that fails UTF-8 validation
(`Failed to read file as UTF-8 ... invalid utf-8 sequence of 2 bytes from
index 11`). The first corruption is at byte offset 11: bytes `e2 ba 01` where
`e2 ba a1` (UTF-8 for `⚡`) was clearly intended — the third byte is `0x01`
(C0 control) instead of `0xa1`. The file also uses `\r\n` line endings.

This violates `CLAUDE.md:26` ("UTF-8 encoding only in all text files"). Because
`AGENTS.md` is the canonical agent-operating-rules document for this hub, an
agent that tries to read it with strict UTF-8 will fail.

**Recommendation**: rewrite `AGENTS.md` with valid UTF-8 (`⚡` → `\xe2\xba\xa1`)
and LF line endings. This requires reading the current content via a
non-UTF-8 fallback first. Deferred from this PR — touching `AGENTS.md` could
change agent behaviour and is out of T0 scope; flagged here for a follow-up
PR (`fix(phenoXdd): repair AGENTS.md UTF-8 corruption`).

### 6.3 `docs/reference/index.md:8-10` — references non-existent root files

`docs/reference/index.md:8-10` claims canonical sources include root-level
`ADR.md`, `PRD.md`, and `FUNCTIONAL_REQUIREMENTS.md`. **None of these files
exist at the repo root.** The actual SSOTs are `docs/reference/adr.md`,
`docs/reference/prd.md`, and `docs/reference/requirements.md` respectively
(declared as such in `STATUS.md:14`).

**Recommendation**: change `docs/reference/index.md:8-10` to point to the
`docs/reference/` paths. Deferred from this PR — out of T0 scope.

## 8. Charter reminder (for agents and humans)

This repository is a **documentation-only hub**. Per
`docs/reference/adr.md:7`:

> Documentation-only repository, no runtime artifacts.

Per `docs/reference/prd.md:7-9`, the hub exists to:

- Provide the canonical reference for engineering methodologies and
  governance practices.
- Keep the corpus usable by both humans and agents.
- Preserve architectural guidance in a stable, reviewable format.

If you intend to add a `Cargo.toml`, a `package.json` at the repo root, a
`go.mod`, a `setup.py`, a `pyproject.toml`, a `rust-toolchain.toml`, a
language-specific CI step (`cargo test`, `go test`, `pytest`, `npm test`,
etc.), or any other runtime artefact, **stop and consult the SSOT** at
`docs/reference/{prd,adr,requirements}.md` first. The hub's design intent is
that downstream consumers (`phenoAI`, `phenoData`, `phenoDesign`,
`phenoRuntime`, `phenoLang`, …) own the runtime; this hub owns the methodology.

## 🏗️ Core Components

### 1. Commit Generation (`zsh-git-ai`)
The primary interface for creating high-quality, context-aware commit messages.
*   **Trigger**: Invoked when running `git commit` without the `-m` flag (or via a specific alias).
*   **Context**: The plugin automatically runs `git diff --cached` and passes the output to the configured LLM.
*   **Output**: Generates a standard "Conventional Commits" message (e.g., `feat: implement login logic`).

### 2. Intelligent Commit Philosophy
In the 2026 workflow, commit messages serve two masters:
1.  **Humans**: Need to understand the *Why* behind a change.
2.  **AI Agents**: Need to understand the *What* for automated changelogs and regression testing.

**Ultra-Parity Standard**:
-   **Header**: Generated by AI (The "What").
-   **Body**: Prompted for or manually added by the developer (The "Why").
